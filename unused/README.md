## contaminated_datasets/  — DO NOT USE, DO NOT RE-IMPORT

| File | Why |
|---|---|
| `dataset_FABRICATED.csv` | Was `Datasets/dataset.csv`. Nine columns (`Fever_Duration`, `Body_Temperature`, `Platelet_Count`, `WBC_Count`, 5 symptom flags) were appended to the Mendeley file with values generated **conditional on the label**. Dengue-negatives span 36.0–37.6 °C, positives 38.1–40.6 °C — zero overlap across 1,000 patients. Any model trained on it returns AUC ≈ 1.000. |
| `mendeley_zdtc3n6xv2_DEGENERATE_LABEL.csv` | The original Mendeley/Kaggle release (`Not Used/dataset (2).csv`). `Outcome == IgG` for **1,000 of 1,000 rows** — the label is a copy of a predictor column. There is no honest classification task in this file. Mirrored on Mendeley (`10.17632/zdtc3n6xv2`), Kaggle (`kawsarahmad/dengue-dataset-bangladesh`) and Hugging Face (`fairhealth/bangladesh-dengue`) — all three are the same contaminated file. |
| `national_monthly_2008_2018_SUPERSEDED.csv` | Fine data, but OpenDengue v1.3 covers the same ground through 2025 with a peer-reviewed provenance chain. Cite that instead. |
